# Release Notes — v1.0.8

## ✨ New

### "About" Dialog

A new **About** button next to Settings in the header opens a dialog with:

- The app version
- A short guide to using the app (creating a chart, profiles, the right-hand tabs, AI interpretation and prompt generation)
- Notes on use
- Licenses (MIT for the original source code; AGPL v3 for the distributed program as a whole because of the bundled kerykeion) and the icon credit
- Links to the **official site**, GitHub and the release page (opened in your browser)

The dialog follows the language selected in Settings (Japanese / English).

### Official Site

Liber Caeli now has an official site: **https://caeli.osprey74.com** (Japanese / English), with downloads for Windows and macOS.

# リリースノート — v1.0.8

## ✨ 新機能

### 「このアプリについて」

ヘッダーの「設定」の左に「このアプリについて」ボタンを追加しました。次の内容を表示します。

- アプリのバージョン
- 使い方の手順（チャートの作成、プロファイル、右側のタブ、AI 解釈とプロンプト生成）
- ご利用にあたっての注意
- ライセンス（独自のソースコードは MIT、同梱の kerykeion により配布物全体は AGPL v3）とアイコンのクレジット
- **公式サイト**・GitHub・リリースページへのリンク（既定のブラウザで開きます）

表示は、設定で選んだ言語（日本語／英語）に連動します。

### 公式サイト

Liber Caeli の公式サイトを公開しました：**https://caeli.osprey74.com**（日本語／英語）。Windows と macOS のダウンロードもこちらから行えます。
